Siddham IAST Studio（離線版）

使用方式
1. 解壓縮 ZIP。
2. 直接以 Chrome、Edge 或 Firefox 開啟 index.html。
3. 不需要網路連線，也不需要安裝任何程式。

功能
- IAST 輸入：輸入 IAST，自動生成 Unicode 悉曇。
- 悉曇對照編輯：IAST 可編輯，悉曇唯讀；可複製、儲存 JSON 專案、開啟專案、匯出內嵌字型 HTML。
- 輸入法說明：常用 ASCII 速記對照。

注意
- 請保留 assets 資料夾與 index.html 的相對位置，否則字型與轉寫程式無法載入。
- Ap 毛筆字型的複雜連字會以 Noto Sans Siddham 自動替補，以避免字形分離。
